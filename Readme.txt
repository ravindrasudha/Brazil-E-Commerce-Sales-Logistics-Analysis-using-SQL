# 🇧🇷 Brazil E-Commerce Sales & Logistics Analysis using SQL

## 📌 Project Overview

This project presents an end-to-end SQL analysis of a Brazilian e-commerce dataset containing over **100,000 customer orders** placed between **2016 and 2018**.

The objective was to analyze customer purchasing behavior, sales performance, logistics efficiency, freight costs, payment trends, and regional business performance to generate actionable business insights.

---

## 📊 Dataset Information

The dataset contains **8 relational tables**:

| Table | Description |
|--------|-------------|
| Customers | Customer demographic and location information |
| Orders | Order details and delivery dates |
| Order Items | Product-level order information |
| Products | Product details |
| Sellers | Seller information |
| Payments | Payment methods and payment values |
| Reviews | Customer review scores |
| Geolocation | Customer and seller location data |

# 📌 Key Business Insights

- Order volume increased significantly between 2016 and 2018.
- São Paulo generated the highest number of customers and sales.
- Customer purchases peaked during afternoon hours.
- Credit Card was the most preferred payment method.
- Remote regions experienced significantly higher freight costs.
- Urban regions achieved faster delivery times.
- Seasonal demand increased during festive periods.

---

# 💡 Business Recommendations

- Establish regional warehouses in high freight-cost areas.
- Optimize delivery routes to reduce logistics costs.
- Improve last-mile delivery performance.
- Launch targeted marketing campaigns in high-performing states.
- Prepare inventory ahead of seasonal demand.
- Promote installment payment options for high-value products.
